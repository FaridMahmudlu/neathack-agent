## X / LinkedIn — launch post

> Shipping AI agents is easy. Debugging them is archaeology.
>
> At #neatHack2026 we built **Autopsy** — an agent that debugs other
> agents. Feed it a failed run and it:
> • reads the @neatlogs trace to find where it went wrong
> • walks @entire_dev checkpoints to find WHICH coding session broke it
> • reads the session transcript to understand why
> • returns a diagnosis with evidence pointers + the fix
>
> Demo: it caught a `reverse=False` regression in our agent's search and
> named the exact checkpoint that introduced it.
>
> Repo: https://github.com/FaridMahmudlu/neathack-agent
> Built with neatlogs + Entire + cfo.ai
